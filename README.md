# Scaling pollinator camera-trap data

This repository contains the R scripts used to process camera-trap detections, fit species-specific temperature–activity models, project camera-derived temperature responses spatially, and validate temporal predictions against independent TERENO pan-trap data.

The analysis is organised as a four-step workflow:

1. preparation of camera-trap, temperature, WorldClim, and GBIF data;
2. fitting and evaluation of temperature–activity models;
3. spatial projection of the camera-based models and comparison with GBIF occurrences; and
4. temporal validation against independent TERENO wild-bee monitoring data.

The scripts are intended to be run in numerical order from the root directory of this repository.

---

### Folder contents

- `scripts/` contains the four R scripts used for the analysis.
- `raw_data/` contains input data obtained from external sources.
- `r_data/` contains intermediate R objects generated by the scripts.
- `results/` contains figures, tables, prediction rasters, model summaries, and validation outputs generated during the analysis.

## 3.2 Local temperature data for the camera study

Hourly temperature data for the **Aarhus South (06074)** weather station were obtained from the Danish Meteorological Institute (DMI). The analysis uses observations from June to September 2019.

To simplify reproduction of the workflow and to ensure that the exact files used in the analysis are available, the four CSV files are included directly in this repository. DMI Open Data are licensed under **CC BY 4.0**.

No manual WorldClim download is required.

It can be downloaded from **Zenodo:** `<ZENODO TERENO DATA DOI/URL TO ADD>`

Relevant source references:

> Frenzel, M., Preiser, C., Dussl, F., Höhne, R., Nickels, V., & Creutzburg, F. (2016). ### `dwd_tmax.csv`

This file contains daily maximum air temperature from six stations of the German Weather Service (Deutscher Wetterdienst, DWD).

Source:

> DWD Climate Data Center (CDC): Tägliche Stationsmessungen des Maximums der Lufttemperatur in 2 m Höhe in °C für Deutschland, Version v21.3.

DWD Climate Data Center portal:

<https://cdc.dwd.de/portal>

Product code:

```text

```

The prepared file contains six DWD stations and has a complete date range from 1 January 1881 to 17 August 2024. The temporal-validation script uses the period required for the TERENO analysis.

The expected columns are:

- `Produkt_Code`
- station identifier
- date
- daily maximum temperature
- `Qualitaet_Byte`
- `Qualitaet_Niveau`

The script maps the following DWD station IDs to TERENO sites:

| TERENO site | DWD station ID |
|---|---:|
| FBG | 2704 |
| GFH | 3226 |
| HAR | 4032 |
| SIP | 2044 |
| SST | 4036 |
| WAN | 3126 |

### `landuse.csv`

This file contains landscape-composition and habitat-diversity metrics for 95 pan-trap sampling locations within the six TERENO agricultural sites.

Source:

> Slabbert, E., Knight, Tm., Wubet, T., Frenzel, M., Singavarapu, B., & Schweiger, O. (2024). Climate and land use primarily drive the diversity of multi-taxonomic communities in agroecosystems. *Basic and Applied Ecology*, 79, 65–73. https://doi.org/10.1016/j.baae.2024.06.003

The variables used by `04_temporal.R` include measures of crop diversity, crop richness, semi-natural habitat, arable land, forest, managed grassland, urban habitat, mass-flowering crops, and EUNIS habitat richness and diversity.

# 4. Run the analysis

Run the scripts in numerical order:

```text
01_data_prep.R
02_activity_models.R
03_SDMs.R
04_temporal.R
```

The repository root must remain the working directory.

It is recommended to **restart R before each script** so that each analysis step starts from a clean session.

For example, the scripts can be run from the R console as follows.

### Step 1 – data preparation

```r
rm(list = ls())
source("scripts/01_data_prep.R")
```

After this script finishes, restart R.

### Step 2 – temperature–activity models

```r
rm(list = ls())
source("scripts/02_activity_models.R")
```

After this script finishes, restart R.

### Step 3 – spatial projections and GBIF evaluation

```r
rm(list = ls())
source("scripts/03_SDMs.R")
```

After this script finishes, restart R.

### Step 4 – temporal validation

```r
rm(list = ls())
source("scripts/04_temporal.R")
```

Some model-diagnostic plots are also displayed interactively while the scripts are running.

# 5. What each script does

## `01_data_prep.R`

This script prepares the principal input datasets.

It:

- imports camera-detection CSV files;
- applies the camera-detection confidence threshold;
- removes class 1 from the camera analysis;
- aggregates detections to hourly observations;
- reconstructs camera sampling effort using `recording_dates.csv`;
- joins camera observations to hourly temperature data;
- aggregates the camera data to daily abundance and daily maximum temperature;
- downloads and crops WorldClim BIO5;
- imports the GBIF occurrence download;
- applies the GBIF filtering criteria; and
- writes species-specific cleaned GBIF occurrence files.

Main intermediate files generated in `r_data/`:

```text
cam_hr.RData
temp_orig.RData
cam_day_tmax.RData
```

---

## `02_activity_models.R`

This script fits species-specific negative-binomial temperature–activity models to the daily camera-trap data.

For each focal species, it:

- accounts for daily camera effort;
- fits a quadratic temperature-response model;
- fits an intercept-only null model;
- compares the temperature model against the null model;
- checks model convergence;
- simulates model residuals;
- produces temperature-response predictions and confidence intervals; and
- generates the temperature-response figure and model-comparison table.

Outputs are written to:

```text
results/
```

---

## `03_SDMs.R`

This script projects the camera-derived temperature responses onto the WorldClim BIO5 raster.

It:

- refits the species-specific temperature–activity models;
- predicts the response across the BIO5 raster;
- aggregates the prediction rasters;
- scales predictions for visualisation;
- saves species-specific prediction rasters;
- overlays cleaned GBIF occurrences;
- calculates Boyce index values; and
- creates the multi-species spatial prediction figure.

Outputs, including GeoTIFF prediction rasters, maps, and Boyce-index tables, are written to:

```text
results/
```

---

## `04_temporal.R`

This script performs the independent temporal validation for:

- *Bombus terrestris*
- *Bombus lapidarius*

It:

- fits the camera-based temperature models for the two species;
- predicts daily activity from DWD daily maximum temperature;
- aggregates predictions across TERENO pan-trap sampling intervals;
- aggregates observations and predictions to annual values;
- fits negative-binomial validation models;
- evaluates annual temporal correspondence;
- calculates site-level temporal skill;
- compares temporal skill with landscape variables;
- clusters correlated habitat variables;
- fits the habitat-effect model; and
- generates the validation and habitat-effect figures and tables.

Additional intermediate files are written to `r_data/`, and final outputs are written to `results/`.
